# MoneyTag
GitHub Pages-এ লাইভ করার ধাপ:
1. github.com-এ নতুন repository খুলুন (যেমন `moneytag`), Public রাখুন।
2. `index.html`, `.nojekyll`, `README.md` আপলোড করুন (Add file → Upload files → Commit)।
3. Settings → Pages → Branch: `main` / `(root)` → Save।
4. ১-২ মিনিট পর `https://আপনার-ইউজারনেম.github.io/moneytag/` এ সাইট লাইভ।

## গুরুত্বপূর্ণ
এটি ফ্রন্টএন্ড প্রোটোটাইপ। ডাটা ব্রাউজারের localStorage-এ থাকে (ডিভাইসভিত্তিক), তাই সত্যিকারের ইউজার, টাকা ও ভেরিফিকেশনের জন্য ব্যাকএন্ড (যেমন Firebase/Supabase) এবং বিকাশ/নগদ পেমেন্ট গেটওয়ে লাগবে।
