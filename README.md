# Moneytag - White UI & Supabase Deployment Guide

এই প্যাকেজে আপনার লোগো (`Moneytag | Work & Hire`) এবং প্রিমিয়াম হোয়াইট (Clean White) ব্যাকগ্রাউন্ড ডিজাইন সহ সম্পূর্ণ সোর্স কোড রয়েছে।

## লাইভ করার নির্দেশিকা:
1. Supabase-এ প্রজেক্ট তৈরি করে `supabase_schema.sql` রান করুন।
2. `index.html` ফাইলে আপনার Supabase API URL ও Key বসান।
3. GitHub-এ আপলোড করে GitHub Pages থেকে ওয়েবসাইট লাইভ করুন।
